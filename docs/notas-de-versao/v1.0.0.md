# CadCli 1.0.0

Primeira versão pública do CadCli, aplicação desktop Win64 para cadastro, pesquisa e emissão de relatórios de clientes.

## Funcionalidades

- Cadastro, alteração, pesquisa e exclusão de clientes.
- Validação de CPF/CNPJ, CEP e data de nascimento.
- Consulta de endereço pelo ViaCEP.
- Pesquisa de clientes por ID, nome, CPF/CNPJ, CEP, cidade, estado e data de nascimento.
- Relatório de clientes com filtros por intervalo de IDs, cidade e estado, ou todos os registros.
- Proteção contra exclusão dos clientes reservados pelo sistema.
- Criação e atualização automática do banco de dados por migrações versionadas.

## Instalação

- Instalador exclusivo para Windows x64.
- Instalação opcional do Firebird 3 x64 como serviço local, marcada por padrão.
- Preservação do arquivo `cadcli.fdb` durante atualizações e na desinstalação.

## Observações

- Esta versão foi compilada com edições de avaliação do DevExpress VCL e do ReportBuilder. Por isso, um aviso de trial é exibido ao iniciar o programa e uma faixa de demonstração aparece na visualização dos relatórios.
- O CadCli requer o Firebird 3 x64 disponível como serviço local.
